# 🏋️ IronVitas - Landing Page Comercial

Projeto front-end desenvolvido para simular a página comercial de uma academia moderna.

A proposta do projeto foi praticar conceitos fundamentais de desenvolvimento web, organização de código e criação de interfaces inspiradas em aplicações reais do mercado fitness.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## 🎯 Funcionalidades

✅ Navegação entre seções  
✅ Slider/carrossel funcional  
✅ Troca automática de banners  
✅ Controle manual do slider  
✅ Layout responsivo  
✅ Interface moderna inspirada em landing pages fitness
